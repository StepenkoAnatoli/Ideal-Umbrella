# Changelog

Notable changes to Ideal-Umbrella. `HISTORY.md` is the narrative history and `research/progress-log.md` the full work log; this file is the short summary.

## [Unreleased]
### Added
- `config/add_to_repo.py --handoff-at TOKENS` writes `env.IDEAL_UMBRELLA_HANDOFF_AT` (as a string) into the repository's `.claude/settings.json`, so one repository can set its own hand-off threshold. Other `env` keys stay; a different value is kept unless `--force`. A template key whose value is an object is now merged key by key instead of compared as a whole.
- `scripts/ledger.py`: run by hand after a measurement, it appends one JSON line (date, Claude Code version, new-session fixed tokens, first-call cache write, number of tools, deny list applied, note) to `research/measurements.jsonl` and prints the change since the previous line. A torn or hand-edited line is skipped and counted; a file it cannot write is a one-line error. The ledger starts with the 71,396-token observation, transcribed from the README, and the README's fixed-load line cites it (checked by `tests/test_docs_match_source.py`).
- `config/install.py` manages only a marked section of `~/.claude/CLAUDE.md` (between `<!-- Ideal-Umbrella rules: begin -->` and `<!-- Ideal-Umbrella rules: end -->`) instead of replacing the whole file; the user's own text stays. `config/uninstall.py` removes only that section and deletes the file only when the install created it and nothing else is left; `--verify-only` compares only the section. Broken marker lines stop both before any write. Installs from the whole-file installer are converted on the next run, and their backup is still restored on uninstall. Premortem: `research/premortem-marker-section.md`; tests: `tests/test_claude_md_section.py`.
- `CONTRIBUTING.md` (failing test first, fix the class, the three recurring classes, stdlib only, `-I` for untrusted input, both OSes, docs with the code) and `.github/PULL_REQUEST_TEMPLATE.md` (what changed, class fixed, commands actually run, docs touched). README "Security model of the hook": what the hook reads and writes and why it never blocks a prompt.
- `tests/test_docs_match_source.py`: the heredoc in `config/cloud-setup.sh` must equal `config/CLAUDE.md` plus the cloud-only line, every path in README "Contents" must exist, the README settings table must match `config/user-settings.json` (deny list and the two numeric keys), and every command in README "Tests" must be a CI step. Each check also runs on a drifted copy to show it catches the drift.
- CI runs pyflakes over the tracked Python files and tests Python 3.10 and 3.13 on Ubuntu besides 3.12; Windows stays on 3.12. README "Quick start" states the supported range (3.10 and later); `pyflakes` is in `requirements-dev.txt`.
- `config/uninstall.py` (with `--dry-run`): undoes `config/install.py` from the install record, restoring earlier values and the CLAUDE.md backup.
- `config/install.py` writes `~/.claude/ballast/install-record.json` with what it added or replaced.
- `IDEAL_UMBRELLA_TAIL_BYTES` for how much of the transcript end `hooks/context_check.py` reads.
- `scripts/unused_tools.py`: tool-call counts from transcripts, flags denied tools that were used.
- GitHub Actions: pytest, the keyline suite and a JSON check on Ubuntu and Windows.
