# Changelog

Notable changes to Ideal-Umbrella. `HISTORY.md` is the narrative history and `research/progress-log.md` the full work log; this file is the short summary.

## [Unreleased]
### Added
- `config/uninstall.py` (with `--dry-run`): undoes `config/install.py` from the install record, restoring earlier values and the CLAUDE.md backup.
- `config/install.py` writes `~/.claude/ballast/install-record.json` with what it added or replaced.
- `IDEAL_UMBRELLA_TAIL_BYTES` for how much of the transcript end `hooks/context_check.py` reads.
- `scripts/unused_tools.py`: tool-call counts from transcripts, flags denied tools that were used.
- GitHub Actions: pytest, the keyline suite and a JSON check on Ubuntu and Windows.

### Fixed
- `keyline/keyline_hook.py`: a dotfile under `notes/` or `plans/` (`.gitignore`, `.DS_Store`), or a file under a dot folder there (`notes/.trash/x.md`), is not a note; `--watch` without a pattern, or any other flag, is one stderr line and exit 1 instead of a silent fall-back; a note or rendering that is not UTF-8 is one stderr line with the file name and exit 1 (a not-UTF-8 rendering is no longer blamed on the note); when only the rendering check fails the header names the rendering to fix, not the note; `.he.md` is a rendering too, a note is checked against every rendering it has, and two notes beside one rendering are a finding of their own, from whichever of the files is written (the first line says to keep the one it renders; the checks wait until one note is left); a `--watch` pattern that spells the dot at that component (`notes/.todo.md`, `notes/.*`, `notes/.trash/*`) names a dotfile or a file under a dot folder, while `notes/*` does not, as in a shell (the dotfile rule applied before the patterns and looked at the file name only, and fnmatch's `*` would match the dot); a file name that is not UTF-8 is a backslash escape in the one stderr line, not a traceback (`reconfigure(encoding=...)` had reset `errors=` to strict).
- `keyline/measure.py`: a named file that cannot be counted, or a folder with nothing to count, is an error (exit 2); a tiktoken data failure is one line, exit 1; a symlinked sub-folder, on Windows a junction too, prints a skip line instead of vanishing; the unreadable-file skip now has a test.
- `scripts/usage_breakdown.py`, `scripts/unused_tools.py`: an unreadable transcript is one stderr line and the others are still counted. `scripts/usage_breakdown.py`, `scripts/toolresult_share.py`, `scripts/usertext_split.py`, `scripts/usertext_top.py`: wrong-typed transcript fields (a `usage` list, an `id` list, a null `text`, a non-string role) are skipped; a UTF-8 BOM is accepted in transcripts, `user-settings.json`, `plugin.json` and `.mcp.json`.
- `scripts/plugin_cost.py`: an output folder that does not exist, or a tiktoken load failure, is one line and exit 1; plugins under a hidden intermediate folder (`.plugins/cache/`) are counted; a folded or literal YAML indicator (`>`, `|-`) is stripped from the description.
- `keyline/keyline_check.py`: every kind but a date, a time and a timestamp is now looked up by extraction, as numbers were, so a path, file name, proper noun, identifier or hash is not found inside a longer token of the rendering (`notes/a.txt` in `notes/a.txt.bak` or `notes/a.txt/`, `report.pdf` in `report.pdf.gpg`, `Jean-Luc` in `Jean-Luc-Picard`, `API` in `API.md`); a Hebrew prefix glued to a path (`ב-__tests__/`) and a name the rendering moves to a sentence start still count. A date and a time written as two tokens (`2026-10-25 14:30`) are present in the ISO form (`2026-10-25T14:30Z`); only the other direction was accepted. A hex digest of up to 128 digits (sha256, sha512) is one invariant; the hash rule stopped at 40, so a changed sha256 passed. A capitalised name with a Latin diacritic (`Zürich`, `Léa`, `Øyvind`, `São`) is a proper noun; it was not extracted, or cut (`Caf` for `Café`), so a swapped name passed. A URL is one invariant with its scheme (`https://example.com/a/b`); it was extracted as the path `//example.com/a/b`, so `https` -> `http` passed. An all-caps month or weekday name longer than three letters (`OCTOBER`, `MONDAY`) accepts its Hebrew form; `DEC` and `SAT` stay acronyms. `No. 5` is a number sign, not a negation (a Hebrew `מס' 5` used to fail with "1 lost"), and a label `May:` is the month, not a possibility hedge. A list marker has at most three digits (also for the lint's numbered-item rule), so `2024. Migration done` keeps the year.
- `keyline/keyline_check.py`: the left token boundary takes the same Latin letters as the right one, so no token starts inside a word (`the ÉCOLE` gave the identifier `COLE`, `école/notes.txt` the path `cole/notes.txt`, and a swapped name passed) and a long run of diacritic pairs is extracted in linear time (16000 `Zé` pairs before `_`: 0.003 s, was 24 s against the hook's 30 s timeout). A file name or path may again start with a Latin letter with a diacritic or a Hebrew letter (`Übersicht.md`, `סיכום.md`, `תיקיה/קובץ.txt`); the linear-time fix had made the first character ASCII, so a swapped Hebrew name passed. An all-caps name with a diacritic (`ÉCOLE`, `NGUYỄN`) is an identifier. `no.` at the end of a line before a numbered item, a date or a time on the next line is a negation (`No. 5` is not), and `May` before a number on the next line is the modal, unless `May` is the whole content of its line (a heading `## May`, a label `**May**`, or a bare `May` line that does not open a question): the month. The prose exception of the path rule (`and/or` is not a path) takes the same letters as the path start, so `él/ella`, `sim/não` and `כן/לא` are prose too, not paths a translated rendering lacks. A dotted digit run before `_` or a letter (`1.1.1…1_`) and a lower-upper letter run (`aAaA…aA_`) are extracted in linear time (16000 pairs: 0.17 s and 0.006 s, were 54 s and 9.7 s against the hook's 30 s timeout); a name that ends in a digit takes a dotted tail (`Python3.12`, `GPT4.5`, `python3.12` are one token each), where the part after the dot used to be a number of its own; a name that ends in a letter takes none and is no token before the dotted number (`No.5`, `Fig.3`, `A.1` yield the number alone, which `No. 5`, `מס' 5` and `איור 3` keep; the abbreviation is prose a rendering translates), a file name takes dotted numbers as well as letter extensions after its stem, in any order, as long as one is a letter extension (`app.log.1`, `backup.tar.gz.1`, `app.log.1.gz`, `syslog.2.gz`, `v1.log.1` are one token each, where the name was lost, cut to `backup.tar` or `app.log.1`, or taken for the version `v1`, and a swapped one passed), and a dotted component that opens a date, a time or a percentage is never part of a name or of its tail (`app.log.2026-10-25T14:30Z` is the file name and the timestamp, `db.sql.14:30` the file name and the time, `notes.txt.5%` the file name and `5%`, where the tail took the year, the hour or the figure and a changed hour passed), and a capitalised word with a digit in it is held to the rendering at a sentence start too (`Python3.12 is required`, where the version was lost to the sentence-start skip). A closed heading `## May ##`, a bold label `**May**:` and `**May** 5` on one line are the month, as `## May`, `**May**` and `May:` are, and so are `***May*** 5` (three closing stars) and `May, 2026` (a comma before a year). A prose slash pair at the end of a sentence (`and/or.`) is prose, not a path. A line of many `May`, `MAY` or marker-led capitalised words is scanned once (80000 bold `May` on one line: 0.3 s, was 6.9 s; 20000 `MAY`: 0.05 s, was 12 s), not once per token. Sentence punctuation after a URL (`https://x.y/z:`, `?`, `!`) is not part of it. A time or timestamp is present in a rendering that adds seconds, fractional seconds or both before the zone the source has (`14:30Z` in `14:30:00.000Z`, `2026-10-25T14:30Z` in `2026-10-25T14:30:00.000Z`) and, when the source has no zone, one that adds a zone too (`14:30:00` in `2026-10-25T14:30:00.000Z`); a dropped zone or fraction stays a miss.
